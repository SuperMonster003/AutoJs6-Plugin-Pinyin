# v1.0.0

###### 2026/07/15

* `Функция` Сервис плагина Pinyin: идентификатор плагина `pinyin`, автоматически обнаруживается и вызывается AutoJs6 через `org.autojs.plugin.PINYIN`
* `Функция` API преобразования: `pinyin.convert(text, options)` возвращает двумерный массив кандидатов с методом комбинирования `compact()`, а `pinyin.simple(text)` возвращает компактную строку
* `Функция` API словарных запросов: `pinyin.fromCodePoint(codePoint)` запрашивает запись чтений одиночного иероглифа, а `pinyin.fromPhrase(phrase)` запрашивает чтения словосочетания
* `Функция` Шесть стилей пиньиня (`NORMAL` / `TONE` / `TONE2` / `TO3NE` / `INITIALS` / `FIRST_LETTER`) плюс режим фамилий (`SURNAME`)
* `Функция` Поддержка нескольких чтений и сегментации: встроены словари одиночных иероглифов, словосочетаний и сегментации плюс модель HMM, параметры `segment` / `heteronym` / `group` включаются по необходимости
* `Функция` Многоязычные ресурсы: метаданные плагина и инструкции охватывают 10 языков
* `Функция` README и CHANGELOG генерируются как многоязычный Markdown из JSON источников через `.python/generate_markdown.py`
